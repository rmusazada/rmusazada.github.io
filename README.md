# Rahim Musazada: Personal Portfolio

Personal portfolio website for **SITE 1101: Principles of Information Systems** at ADA University.

**Live site:** https://rmusazada.github.io

## About this project

I'm a Computer Engineering student at ADA University in Azerbaijan. This site introduces me and shows my course projects. It is a static website built with HTML, CSS, and JavaScript, and it is hosted on GitHub Pages.

## Pages

- **Home** (`index.html`): short introduction and profile photo
- **About** (`about.html`): background, qualifications, and activities
- **Projects** (`projects.html`): course projects with descriptions and images
  - Project 1: Logic gates built on a breadboard
  - Project 2: Hour of Code
  - Project 3: Robotics (LEGO EV3 line-following robot)

Every page has a navigation bar and a footer with a link to this repository.

## Folder structure

```
.
├── index.html
├── about.html
├── projects.html
├── css/
│   └── style.css      # all styling
├── js/
│   └── main.js        # mobile menu and footer year
├── images/            # profile photo, project images, icons
└── README.md
```

## Technologies

- HTML5
- CSS3
- JavaScript (no frameworks)
- Git and GitHub for version control
- GitHub Pages for hosting
- Cursor (AI coding assistant) used to help build the site

## Run it locally

1. Clone the repository:
   ```
   git clone https://github.com/rmusazada/rmusazada.github.io.git
   ```
2. Open `index.html` in a browser, or use the Live Server extension in VS Code or Cursor.
